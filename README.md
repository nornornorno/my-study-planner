# مخططي الدراسي

تطبيق ويب عربي يعمل مباشرة في المتصفح، ومجهز للنشر على GitHub Pages.

الملفات:
- index.html
- style.css
- app.js

البيانات تُحفظ تلقائياً داخل Local Storage في المتصفح. لا يحتاج التطبيق إلى Python أو خادم.

للنشر: ارفع الملفات الثلاثة إلى مستودع GitHub، ثم فعّل GitHub Pages من Settings → Pages واختر Deploy from a branch ثم main و / (root).
